# 🤖 ربات ابری «پالس هوش مصنوعی» برای بله — نسخهٔ ۴.۰

این ربات **۲۴ ساعته و ۷ روز هفته**، هر ~۳۰ دقیقه روی سرور رایگان GitHub Actions اجرا می‌شود:

1. آخرین اخبار هوش مصنوعی را از **۳۴ منبع معتبر دنیا** می‌گیرد (TechCrunch، The Verge، MIT، OpenAI، DeepMind، NVIDIA، Zoomit، ایسنا و…)
2. **توییت‌های افراد معروف AI** را هم می‌خواند (سام آلتمن، ایلان ماسک، کارپاتی، اندرو انگ، یان لکان، دمیس هاسابیس — از طریق Nitter بدون نیاز به API) + تروث سوشال
3. هر خبر را به **فرمت حرفه‌ای ۴.۰** درمی‌آورد:

```
منبع: نام‌منبع
لب کلام خبر — ۲ تا ۳ جملهٔ فارسی روان و ساده
🔗 لینک   (لینک داخل کلمهٔ «لینک» پنهان است)
+ عکس خبر
```

4. توییت‌ها با **ترجمهٔ روان و بدون دخل‌وتصرف** + متن اصلی می‌آیند: `منبع: توییتر — سَم آلتمن`
5. خبرهای یکسان از چند منبع **یک پیام واحد** می‌شوند با ذکر همهٔ منابع و لینک‌ها
6. هیچ خبری دوبار ارسال نمی‌شود (وضعیت در `state.json` ذخیره و commit می‌گردد)

**هزینه: صفر تومان — گوشی هم لازم نیست روشن باشد.**

## 📋 گام‌به‌گام راه‌اندازی (حدود ۱۰ دقیقه)

### گام ۱ — اکانت گیت‌هاب
اگر اکانت نداری، در [github.com/signup](https://github.com/signup) رایگان بساز و ایمیلت را تأیید کن.

### گام ۲ — ساخت ریپو
1. وارد گیت‌هاب شو → گوشهٔ بالا «**+**» → **New repository**
2. نام: `aipulse-bot` — دید (Visibility): **Public** ✅ (پابلیک = دقیقه‌های Actions نامحدود و رایگان)
3. تیک «Add a README» را نزن → **Create repository**

### گام ۳ — آپلود فایل‌ها
در صفحهٔ ریپو روی لینک **«uploading an existing file»** کلیک کن (یا «Add file → Upload files»).
پوشهٔ `aipulse-cloud-bot` را از کامپیوتر **بکش و رها کن**. باید این فایل‌ها بالا بیایند:

```
.github/workflows/bale.yml   ← زمان‌بندی هر ۳۰ دقیقه
bot.js                        ← خودِ ربات
package.json
state.json
README.md
```

⚠️ مهم: پوشهٔ پنهان `.github` هم باید آپلود شود (وقتی پوشه را می‌کشی، خودکار می‌آید). پایین صفحه بنویس `first commit` → **Commit changes**.

> اگر کشیدن پوشه جواب نداد: برای هر فایل «Add file → Create new file» بزن، اسم فایل را تایپ کن (برای workflows اول `.github/workflows/bale.yml` را کامل تایپ کن، اسلش خودش پوشه می‌سازد) و محتوایش را Paste کن.

### گام ۴ — اضافه کردن رمزها (Secrets)
در ریپو: **Settings → Secrets and variables → Actions → تب Secrets → New repository secret**
این سه Secret را بساز:

| Name | Secret (مقدار) | لازم؟ |
|---|---|---|
| `BALE_TOKEN` | توکن ربات بله — همان که داخل اپ هست (از @BotFather بله) | ✅ اجباری |
| `GEMINI_KEY` | کلید جمینی خودت (همین که به من دادی، با `AQ.` شروع می‌شود) | 🔸 قویاً پیشنهاد می‌شود — کیفیت پست‌ها عالی می‌شود |
| `BALE_CHATS` | مقصدها با کاما: `1663835599` (چت خصوصی‌ات) یا `1663835599,@mychannel` | 🔸 اختیاری — پیشفرض همان چت خصوصی‌ات است |
| `GLM_KEY` | کلید GLM-4 از open.bigmodel.cn (پشتیبان جمینی) | ⚪ اختیاری — نبودش هم مشکلی نیست |

> برای گرفتن شناسهٔ کانال خصوصی: یک پست کانال را به ربات فوروارد کن، در اپ «👥 بررسی چت‌ها» را بزن، شناسه را بردار و اینجا بگذار. برای کانال عمومی همان `@نام‌کانال` کافی است.

### گام ۵ — اولین اجرای دستی (تست)
1. تب **Actions** ریپو → سمت راست روی **«AI Pulse → Bale»** کلیک کن
2. دکمهٔ **Run workflow** → **Run workflow** (همان پیشفرض‌ها)
3. روی اجرای جدید کلیک کن و لاگ را ببین؛ باید ببینی: `📡 دریافت ۳۴ منبع خبری…` → `🌐 عنوان: …` → `🤖 لب کلام: …` → `✓ ارسال شد → …`
4. برو داخل بله — پست با فرمت جدید (منبع ← لب کلام ← لینک) و عکس تازه رسیده ✅

### گام ۶ — فعال شدن خودکار
همین! از این لحظه هر ~۳۰ دقیقه خودکار اجرا می‌شود (کرون گاهی چند دقیقه تأخیر می‌خورد — طبیعی است). خود ربات هم `state.json` را commit می‌کند، پس ریپو همیشه فعال می‌ماند و کرونِ ۶۰ روزه خاموش نمی‌شود.

### گام ۷ — جلوگیری از ارسال تکراری اپ
حالا که ربات ابری فعال است، در **اپ گوشی**: تب دستیار → بخش ربات بله → **«⏸ خاموش کردن»** (ارسال خودکار اپ) را بزن. اپ فقط برای خواندن اخبار می‌ماند؛ انتشار ۲۴ ساعته با ربات ابری است.

## 🔎 پیدا کردن شناسهٔ چت (حالت discover)
اگر لاگ خطای `403: permission_denied` یا `chat not found` داد، یعنی ربات به مقصدِ تعیین‌شده دسترسی ندارد. این ۳ قدم:

1. **در بله**: @ailastnewsbot را «مدیر» کانال مقصد کن (اجازهٔ ارسال پیام فعال باشد) — یا اگر مقصد چت خصوصی خودت است، اول به ربات یک پیام بفرست.
2. در گیت‌هاب: تب **Actions** → «AI Pulse → Bale» → **Run workflow** → در منوی **Mode** گزینهٔ **discover** → Run.
3. لاگ را باز کن؛ شناسهٔ همهٔ چت‌هایی که با ربات در ارتباط‌اند را می‌بینی (مثل `• شناسه: 1663835599 | نوع: private`). شناسهٔ درست را در Secret با نام `BALE_CHATS` بگذار و دوباره با Mode = run اجرا کن.

> در حالت discover هیچ خبری ارسال نمی‌شود و state هم ذخیره نمی‌شود — کاملاً بی‌خطر است.

## 🧠 زنجیرهٔ هوش مصنوعی

اگر `GEMINI_KEY` داده باشی: **جمینی** (کیفیت عالی) → اگر سهمیه‌اش تمام شد خودکار **GLM-4** (اگر `GLM_KEY` بگذاری) → در نهایت **موتور رایگان** بدون کلید. یعنی حتی بدون هیچ کلیدی، ربات کار می‌کند. برای هر خبر **«لب کلام»** ساخته می‌شود — ۲ تا ۳ جملهٔ فارسی روان که قلب پست ۴.۰ است؛ اگر موتورها جواب ندادند، پست فقط با «منبع + لینک» می‌رود و چیزی از دست نمی‌رود.

## 🛠 عیب‌یابی

| مشکل در لاگ | معنا / راه‌حل |
|---|---|
| `✕ متغیر BALE_TOKEN تنظیم نشده` | گام ۴ — Secret با نام دقیق `BALE_TOKEN` بساز |
| `بله 401: Unauthorized` | توکن اشتباه است — از BotFather بله توکن را دوباره بگیر |
| `بله 403: Forbidden: permission_denied` | ربات به آن چت دسترسی ندارد → بخش «پیدا کردن شناسهٔ چت» بالا: ربات را ادمین کانال کن یا اول به ربات پیام بده، بعد Mode = discover |
| `chat not found` | شناسهٔ چت اشتباه است یا هنوز به ربات پیام نداده‌ای → Mode = discover |
| `موتور gemini نشد (HTTP 429)` | سهمیهٔ رایگان جمینی موقتاً پر شده → خودکار به موتور بعدی می‌رود؛ نگران نباش |
| `موتور gemini نشد (This operation was aborted / اتصال به جمینی برقرار نشد)` | اتصال سرور گیت‌هاب به جمینی موقتاً کند بود → خودکار موتور بعدی؛ اگر همیشه تکرار شد، نگران نباش چون موتور رایگان جایگزین می‌شود |
| `⚠ منبع … پاسخ نداد (HTTP 429)` | آن سایت سرور گیت‌هاب را محدود کرده — بقیهٔ ۳۳ منبع کافی‌اند |
| workflow اصلاً اجرا نمی‌شود | تب Actions → روی workflow → «Enable workflow»؛ یا یک commit کوچک بزن |
| `تعارض state.json حل شد` | عادی است — دو اجرا همزمان state را عوض کرده بودند؛ خودکار اتحاد می‌شود |
| `push ناموفق` در پایان | مهم نیست — دورهٔ بعد state را ذخیره می‌کند (فقط ممکن است یک خبر دوباره برود) |

## 🔒 امنیت

هیچ توکنی داخل کد نیست — همه در **Secrets** گیت‌هاب که حتی در لاگ‌ها هم مخفی می‌مانند. اگر روزی توکن لو رفت، از @BotFather بله توکن جدید بگیر و Secret را آپدیت کن.
